What We Need to Put DoggyTour Back in the Stores

📅 October 2026 📋 Pre-launch checklist
Situation: We received the DoggyTour source code and need to re-publish the app to the App Store (iOS) and Google Play (Android). The code is ready and runs locally. Before we can ship, we need to confirm who controls the existing server and store accounts — and if no one does, we need to set up replacements. Estimated cost to start fresh: ~$220 one-time + ~$100/month server.

What We Need to Confirm First

🖥️
Backend server access
The app connects to restapi.doggytour.com. Someone controls this server. We need login credentials or hosting provider access to verify it is running and can handle traffic. If no one has access, we set up a new server.
Confirm
🍎
Apple Developer account
An Apple Developer account is required to publish to the App Store and create iOS builds. The existing app listing belongs to whoever created it. We need either the credentials to that account, or to create a new one and re-submit the app from scratch.
Confirm
🤖
Google Play Console account
Same situation as Apple. The Play Store listing belongs to whoever originally published it. We need access to that account, or we create a new one and submit fresh.
Confirm
🔑
Android signing keystore
Android apps are signed with a private key. If we don't have the original keystore file, we cannot publish updates to the existing Play Store listing — Google requires updates to be signed with the same key. We would need to create a new listing.
Critical
✅
Source code
We have the full source code for both the mobile app (React Native) and the backend (NestJS). It compiles, runs locally, and has been tested on Android emulator and iOS.
Ready
✅
Push notifications (OneSignal)
The OneSignal app ID is embedded in the code. The existing OneSignal project should still work as long as the account is accessible. If not, creating a new free account takes minutes.
Ready

If We Have to Start From Scratch

🍎
Apple Developer Program
Required to publish iOS apps. Billed yearly. Includes App Store access, TestFlight for beta testing, and iOS signing certificates.
$99 / year
🤖
Google Play Developer account
Required to publish Android apps. One-time fee. Includes Play Console access and internal/beta testing tracks.
$25 one-time
🖥️
Backend server hosting
A cloud server to run the API and database. A small VPS (e.g. DigitalOcean, AWS, or similar) is sufficient to start. The app's backend is containerized with Docker so setup is straightforward.
~$20–50 / month
🔗
Domain / SSL (if new server)
The existing domain restapi.doggytour.com points to the old server. If we spin up a new one, we either need control of that domain to redirect it, or we update the app to point to a new URL.
~$15 / year
📦
Expo EAS Build (cloud builds)
Used to build the iOS binary without needing a Mac. The free tier gives limited monthly builds; a paid plan is recommended for regular releases.
$0–99 / month

Realistic Timeline to Go Live

Week 1
Confirm what we have access to
Check with original developer: does he have server credentials, store accounts, and the Android signing keystore? This determines whether we recover existing assets or start fresh.
Week 1–2
Set up infrastructure (if needed)
Spin up new server, set up database, point domain, create developer accounts. Backend is already containerized with Docker so deployment is fast.
Week 2
Internal testing
Build and distribute via TestFlight (iOS) and Play Store Internal Testing (Android). Team tests core flows: registration, matching, messaging, payments.
Week 3–4
Fix bugs, submit for review
Address issues found in testing. Submit to App Store (review takes 1–3 days) and Google Play (review takes hours to 1 day).
Week 4
Live
App available to users. Monitor backend logs and crash reports in the first week.

Recommended Next Step

Ask the person who gave us the project ZIP for the following, in order of priority:
  1. The Android signing keystore file — without this we cannot update the existing Play Store listing
  2. Login to the Apple Developer account and Google Play Console
  3. Server hosting credentials — provider name, login, or contact for whoever manages restapi.doggytour.com

If he no longer has any of this, we can rebuild everything from scratch in roughly 2–3 weeks and have the app live in the stores. The source code is complete and working.
